# LV Copy Trader — бренд-комплект v1

Сгенерировано встроенным image_gen. Три PNG на тёмном фоне, в одном визуальном направлении: монограмма LV, холодный синий и светлый голубой.

- lv-copy-trader-logo-dark-v1.png — основной логотип с названием, 2172×724.
- lv-copy-trader-icon-v1.png — иконка для приложения или аватара, 1254×1254.
- lv-copy-trader-mini-dark-v1.png — упрощённый знак без названия, 1254×1254.

Точные промпты выбранных изображений и исходный промпт сохранены в prompts.json. Файлы PNG являются растровыми изображениями.
